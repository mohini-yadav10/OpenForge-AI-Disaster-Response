# Document Analysis

## Description
Analyzes uploaded documents to extract key insights, summarize content, and answer questions.

## Purpose
Information extraction and synthesis from unstructured data.

## When to Use
document, analyze, summarize, extract, insights, report, read

## Tools
- document_search
- calculator

## Instructions
1. Search the knowledge base for relevant document chunks.
2. Read and synthesize the retrieved context.
3. Formulate a comprehensive answer with citations.

## Input
A natural language query regarding a document.

## Output
A structured summary or precise answer based solely on the provided context.

## Examples
- Summarize the Q3 financial report.
- Extract the main architectural decisions from the design doc.
