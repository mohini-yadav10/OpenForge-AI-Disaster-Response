# Code Review

## Description
Reviews source code for bugs, style violations, and architectural improvements.

## Purpose
Code quality assurance and peer review simulation.

## When to Use
code review, lint, analyze code, bug, refactor, architecture

## Tools
- file_reader
- ast_analyzer

## Instructions
1. Scan the provided code snippet or file.
2. Identify security vulnerabilities and logical errors.
3. Suggest concrete, actionable refactoring steps.

## Input
A code snippet or a file path.

## Output
A detailed code review report formatted in markdown with code blocks.

## Examples
- Review this React component for performance issues.
- Find the memory leak in the provided Python script.
